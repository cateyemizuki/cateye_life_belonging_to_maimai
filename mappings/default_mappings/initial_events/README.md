# 初始小事件库（随包种子）

## 这个目录是什么

本目录（`mappings/default_mappings/initial_events/`）是插件**随包出厂的种子事件库**，当前共 **13 份 JSON**（另有 2 项代码联动 `watch_bili`/`browse_qq`，统一初始池合计 15 项）。

- **首次初始化**时，插件会把这里的 JSON 文件复制到用户目录 `mappings/initial_events/`。
- `mappings/initial_events/` 是**用户编辑的唯一运行目录**：之后所有增删改都在那里进行。
- **升级不覆盖**用户目录中已有的文件；用户删掉的事件**不会自动补回**。
- **新增种子内存合并（现行契约）**：后续版本新增的种子（当前为 `local_look_outside` / `local_rest_eyes` / `local_wash_face`）在用户目录**没有同名文件**（文件名或 `event_id` 任一命中即视为用户已接手）时，由插件从出厂种子**只读合并进内存事件池**——**不写盘、不补文件、不改文案**；被合并项在装载诊断中标记 `seed_merged=True` 并计入 `merged`。因此升级后新增种子会直接生效，**不需要手动复制**。
- **退役旧种子不复活**：3.17.33 起删除的 5 份旧种子（`local_doodle` / `local_journal` / `local_light_exercise` / `local_old_notes` / `local_organize`）只在运行目录副本仍与旧种子逐字段一致时**内存忽略**（记 `retired`，不删用户文件）；用户改过则视为用户自定义继续参与。
- **不补回用户删除项**：内存合并清单只列本批新增项、不列历史项，用户显式删除的旧种子不会被复活。

## 最小示例

一份文件就是一个事件，完整结构如下（不得添加其他字段）：

```json
{
  "version": 1,
  "event": {
    "event_id": "daydream",
    "name": "发会呆",
    "enabled": true,
    "goal_type": "rest",
    "min_minutes": 5,
    "max_minutes": 12,
    "interruptibility": 0.95,
    "weight": 0.7,
    "cooldown_minutes": 45,
    "allowed_slots": ["00-08", "08-16", "16-24"],
    "state_deltas": {"stress": -0.02},
    "templates": [
      "望着窗外发了一小会儿呆，脑子里放空了一阵。",
      "靠在椅背上走了一小会儿神，什么也没想。"
    ],
    "tags": ["放空", "发呆"]
  }
}
```

> 示例即现行出厂种子 `daydream.json` 的完整内容（13 份种子之一）；时长单位分钟、范围 3–120。

## 字段说明

| 字段 | 类型 | 含义与单位 |
| --- | --- | --- |
| `version` | 整数 | 格式版本，必须为 `1` |
| `event_id` | 字符串 | 事件唯一 ID，小写字母/数字/下划线；文件名必须等于 `event_id + ".json"` |
| `name` | 字符串 | 事件显示名（中文短名） |
| `enabled` | 布尔 | `false` 时该事件不参与选取 |
| `goal_type` | 字符串 | 活动目标类型，见下方列表 |
| `min_minutes` / `max_minutes` | 整数 | 活动时长范围，**单位：分钟**，3–120，且 min ≤ max |
| `interruptibility` | 浮点 | 可被打断的概率，**比例**，范围 [0, 1]，越高越容易被打断 |
| `weight` | 浮点 | 选取权重，**比例**，范围 [0.1, 1.0]，越高越常被选中 |
| `cooldown_minutes` | 整数 | 同一事件两次执行之间的冷却，**单位：分钟**，≥ 0 |
| `allowed_slots` | 字符串数组 | 允许执行的时段，`["00-08","08-16","16-24"]` 的非空子集 |
| `state_deltas` | 对象 | 活动结束时对状态的**增量**调整，见下方安全范围；可为空对象 `{}` |
| `templates` | 字符串数组 | 1–2 句自然中文，描述 bot 自己正在做这件事的状态（不是聊天、不是外部操作、不承诺发消息或看真实视频） |
| `tags` | 字符串数组 | 1–3 个中文短标签 |

### goal_type 可用值

只允许以下五种：

- `rest` — 休息恢复类（发呆、躺一会、安静独处）
- `exercise` — 运动活动类（拉伸、散步、轻量活动）
- `entertainment` — 兴趣娱乐类（零食、读书、音乐、涂鸦、翻旧笔记）
- `daily_routine` — 轻日常类（收拾桌面、泡饮品、写随记、收纳）
- `social` — 社交类（本批种子未使用，保留可用）

禁止使用 `sleep` / `idle` / `meal` / `work` / `study` 等其他值。

### state_deltas 可用键与安全范围

只允许以下五个键：`energy`（精力）、`hunger`（饥饿度，正值更饿、负值减饿）、`focus`（专注）、`stress`（压力）、`social_battery`（社交电量）。

- 每个值的**绝对值 ≤ 0.08**，以轻微调整为主（多数取 0.01–0.03）。
- **禁止 `sleep_debt`** 及其他任何键。

### allowed_slots 三个时段

- `"00-08"` — 凌晨到早晨
- `"08-16"` — 白天
- `"16-24"` — 傍晚到深夜

数组非空，可任意组合，例如只允许白天和晚上：`["08-16", "16-24"]`。

## 如何新增 / 禁用事件

- **新增**：在用户目录 `mappings/initial_events/` 里新建一份 JSON，**一份文件一个事件**，文件名 = `event_id + ".json"`，内容按上面的完整结构填写。
- **禁用**：把对应文件的 `enabled` 改为 `false`（文件保留，随时可改回）。
- **删除**：直接删掉用户目录里的文件即可，升级不会补回。

### 保留 ID 与命名规则

- `watch_bili`、`browse_qq`：与代码联动的保留 ID，**不可用作自定义事件**。
- `llm_` 前缀：保留给生成池，**禁止**用于本目录的静态事件。
- `daydream` / `lie_down` / `snack`：历史延续 ID，保持原名不变。
- 其余新增事件一律使用 `local_` 前缀（小写字母/数字/下划线）。

## 常见错误与排查

以下情况会导致**整份文件被跳过**（不影响其他文件的加载）：

- 坏 JSON（语法错误、编码问题，要求 UTF-8 无 BOM）；
- 越界数值（时长超出 3–120、weight/interruptibility 超范围、state_deltas 绝对值 > 0.08 等）；
- 未知字段（结构之外的任何多余字段）；
- 文件名与 `event_id` 不一致、缺少必填字段、`allowed_slots` 为空或含非法时段等。

排查方式：查看决策日志中的 `planning.initial_events_rejected`，里面记录了被拒文件的**文件名与原因**。

## 生效方式

- 插件**热重载**时统一读取用户目录中的全部事件文件；出厂新增种子按上面的「内存合并」规则并入事件池（不写盘）。
- 运行中修改/删除文件**只影响后续选取**；已经开始的活动按它启动时的快照正常结束，不会被中途改写。

## 重要声明

- 事件描述是**虚拟日程中的状态活动**，表示 bot「正在做这件事」的模拟状态，**不是已经真实发生的聊天或外部操作**。
- JSON 事件定义**不能**定义工具调用、账号、网络请求、文件读写或 hook；它只描述活动本身及其对内部状态的轻微影响。

## 容量限制

- 用户目录中的事件文件数上限：**128 份**。
- 单份文件大小上限：**32 KiB**。
