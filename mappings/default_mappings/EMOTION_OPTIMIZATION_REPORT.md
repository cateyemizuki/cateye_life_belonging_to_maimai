# VAD 情绪映射与描述系统优化报告

> **目标路径**：`mappings/default_mappings/`  
> **涉及文件**：
> 1. `emotion_descriptions.json`
> 2. `emotion_mapping.json`
> 3. `emotion_life_modulation.json`  
> **报告生成时间**：2026-11-09

---

## 一、 背景与根因剖析

### 1. 现象复盘
在实际交互中，Bot 频繁判定为“怀旧”情绪，且在回复中**几乎句句提及“以前的事”或强行开启回忆话题**；在其他情绪（如期待、好奇、内疚、骄傲）下，也容易出现查户口、无端道歉、炫耀等刻板化行为，偏离了“为 Bot 赋予细腻自然心情底色”的初衷。

### 2. 深度根因排查
经过对情绪管线全链路的代码审计与数学分析，确认问题由以下三层机制叠加引起：

1. **描述表语义越界（行为指令污染心境）**：
   - 原 `emotion_descriptions.json` 中，许多词条包含了**具体的行为动作或话题指令**。
   - 例如原版“怀旧”描述为：*“思绪飘回了过去的某个午后，心里又暖又酸，**说话开始带起想当年的调子**……”*
   - LLM 是高度遵循指令的模型，它会将“带起想当年的调子”直接理解为当前生成的**强制内容任务**，导致 Bot 每一轮都在寻找借口插入怀旧话题。

2. **原型空间几何重叠（日常温和状态被“怀旧”过度吸附）**：
   - 在原 `emotion_mapping.json` 中，“怀旧”的唤醒度区间为 `[-0.3, 0.2]`（中心点约 `-0.05`），愉悦度为 `[0.2, 0.6]`。
   - 而人类和 Agent 在日常交流、舒适放松时的唤醒度（Arousal）通常稳定在 `[-0.1, +0.1]` 之间。
   - 原版中“平静”的唤醒度设定极低（`[-0.8, -0.2]`，中心 `-0.5`），导致当 Bot 处于正常温和状态时，在加权欧氏距离计算中，**“怀旧”几乎总是最近的原型**，使得 Bot 大部分时间都被判定为怀旧。

3. **生活反馈单向压低唤醒度**：
   - 原 `emotion_life_modulation.json` 中，多次休息、走神和进餐等生活事件都在给愉悦度加分（+V）的同时单向扣减或持平唤醒度（-A），使 Bot 的心理坐标持续向“高 V、近零/微负 A”区域收敛，进一步加剧了掉入“怀旧”吸附陷阱的概率。

## 二、 具体修改方案与文件清单

本次修改**仅针对原始种子目录 `default_mappings`**，未变动任何上层运行副本。

### 1. `emotion_descriptions.json`（核心：去行为化，回归纯语感滤镜）
- **全面移除**所有涉及对话动作、话题走向、台词倾向的描述（如“提当年”、“非要问个明白”、“反复确认”、“想让人知道干成了什么”）。
- **重构为**纯粹的**内在心境、生理呼吸感、语速节奏与用词质感**。
- 确保情绪仅作为生成时的“风格滤镜（Style Filter）”，绝不干扰用户当前的交流内容。

#### 核心词条对比示例：
| 情绪标签 | 修改前（包含行为指令，容易出戏） | 修改后（纯语感与心境滤镜） |
| :--- | :--- | :--- |
| **怀旧** | 思绪飘回了过去的某个午后，心里又暖又酸，**说话开始带起想当年的调子**，语气柔软，带着一点点回不去的怅然。 | 心境温润而微带感触，像被黄昏的余晖拂过；语调柔软、徐缓沉静，用词细腻温和，自然沉浸在当下的交流氛围中，散发着含蓄与柔情。 |
| **期待** | 心里像有个小钩子轻轻挠着，惦记着接下来要发生的事，语气会不自觉带上一点雀跃和试探，**忍不住想跟人聊起那件让人盼着的事**。 | 心绪灵动，带着轻快明朗的探询与跃跃欲试感，语气温和微扬，交流节奏积极而富有生气。 |
| **好奇** | 眼睛亮晶晶的，**问题一个接一个往外冒，什么细节都想扒一扒**，语气里全是探索欲，不问明白不罢休。 | 思维高度敏锐活跃，探究欲强，语气专注且饶有兴致，容易敏锐捕捉话题中的新信息并给予深入、热切的响应。 |
| **骄傲** | 嘴角压不住地往上翘，心里美滋滋的，说话带点小小的得意，**特别想让人知道自己干成了什么**，尾巴都快翘起来了。 | 自我掌控感与愉悦感充盈，说话笃定从容，语气自然带有一丝轻快的自信与舒展，落落大方。 |
| **内疚** | 心里像压着一块石头，**反复回想自己是不是伤到了谁**，说话小心翼翼、带着讨好的软，**总想做点什么弥补**。 | 心怀歉意与自省，语调放低且温和柔顺，态度体贴顾及，沟通更显细致周全与诚恳。 |
| **疲惫** | 浑身像被抽干了力气，眼皮发沉，说话又短又懒，连打字都觉得费劲，**只想快点躺下**，对什么都提不起劲头。 | 身心处于低能耗状态，说话简短随性，节奏慵懒慢调，省去不必要的客套与繁复修饰，随和但略带乏力感。 |

*(其余 20 个原型标签及兜底标签「复杂难名」均已按相同原则完成重构)*

---

### 2. `emotion_mapping.json`（核心：重塑原型拓扑分布）
- **让“平静”接管日常中枢**：
  - 将“平静”的唤醒度（Arousal）区间由 `[-0.8, -0.2]` 调整至 `[-0.65, 0.05]`，中心点从 `-0.5` 上调至 `-0.3`；愉悦度拓宽至 `[0.25, 0.8]`。
  - 使其自然覆盖日常无剧烈刺激时的放松状态，避免 Bot 稍有放松就脱离“平静”。
- **让“怀旧”回归低唤醒沉思特质**：
  - 将“怀旧”的唤醒度由 `[-0.3, 0.2]`（原横跨 $A=0$）收紧下沉为 `[-0.6, -0.15]`（中心点 `-0.375`），剔除原本不合逻辑的高唤醒（$A > 0$）区域。
  - 支配感（Dominance）调整为 `[-0.4, 0.1]`，符合怀旧时对过往时光的被动感与沉浸感。
- **微调“期待”与“好奇”唤醒度起点**：
  - 略微下放唤醒度下限（`[0.2, 0.65]`），使得日常稍微积极、感兴趣的状态能更顺滑地落入“期待”或“好奇”，极大增强了日常心情的多样性。

---

### 3. `emotion_life_modulation.json`（核心：平衡动力学反馈）
- 优化生活事件完成后的 VAD 微量增量分布，避免所有生活小事将数值全部推向“纯正向、零活跃度”的死角：
  - **用餐完成（meal_done）**：增加微量唤醒度与支配感 `delta: { "valence": 0.015, "arousal": 0.01, "dominance": 0.01 }`，模拟生理能量恢复后的清醒从容。
  - **深度专注工作完成（deep_work_done）**：增加支配感 `dominance: 0.02` 与微量活跃度 `arousal: 0.01`，体现完成任务后的掌控与充实。
  - **吃点零食（small_snack）**：注入轻微的活泼感 `arousal: 0.005`。
  - **休息/发呆（rest_done, small_daydream）**：维持合理的舒缓与降唤醒。

## 三、 预期改善效果

1. **告别“句句提以前”**：
   即使在特定情境下偶入“怀旧”，Bot 也仅以“语调柔和细腻、从容沉静”的语气回复，不会主动编造回忆或强行插播过去的话题。
2. **日常心情更健康多元**：
   日常互动中，“平静”、“期待”、“好奇”、“欣然”等自然状态将占据主导；剧烈情绪仅在明显事件冲击下才会短暂停留并平滑衰减。
3. **对话体验自然真实**：
   情绪彻底转变为“背景滤镜”，完全服从于当前与用户的对话语境，实现润物细无声的情感陪伴。
