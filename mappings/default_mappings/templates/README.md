# LLM 兜底模板

每个生成事件都有同名 JSON，定义输出类型、消耗警告档位和保守默认值。large / medium / small 分别在输出超过 16000 / 10000 / 4000 Token 时提示；small 事件最多重试一次。

`event_pool.json` 提供小事件的活动文案。日程作息模板在 `schedule_layout.json` 中，按实际作息构造，不固定用户起床或入睡时刻。已有兴趣、观看分析、活动偏好缺少证据时继续使用旧结果或中性默认值，不把模板当成真实观察或真实偏好。

使用模板会写入统一生成日志，并在用量页显示模板名称及原因。模板记录不算额外模型调用，不计入 Token 统计。

遵循映射表约定：本目录是出厂种子；首次缺表时复制到 `mappings/templates/`。运行时优先读取表层，更新不覆盖用户改过的内容。损坏时读取出厂种子或保守默认值。
