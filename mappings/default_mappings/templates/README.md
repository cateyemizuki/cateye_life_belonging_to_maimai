# 统一 LLM 保守模板

同名事件 JSON 声明输出协议、告警档位和保守默认值；运行优先读取表层 `mappings/templates/`，缺失时从随包种子补齐，升级不覆盖用户模板。协议和业务 validator 共同限制结果，编辑模板不能赋予外部动作权限。

输出告警档位为 large/medium/small，阈值分别16000/10000/4000输出Token；轻量任务共用最多一次失败重试。请求/格式修复/语义失败由统一策略管理，业务外层不再叠失败重试。

`schedule_layout.json` 按实际作息锚点构造保守日意图；`event_pool.json` 是事件文案种子。`schedule_activity_attributes.json` 为最终候选的批量模块属性作业注册协议，失败路径逐条 null，即使编辑模板也不直接启用观看或QQ行为。

模板不是实际观察、真实观看或已发生经历，模板记录不增加模型请求或Token。当前有效生成判断与请求ID关联，界面展示裁剪不改变历史类别；来源未知时显示未知，不推为正常。

此层由本项目统一LLM管线维护，早期工具来源和改造范围见[第三方说明](../../../THIRD_PARTY.md)。
