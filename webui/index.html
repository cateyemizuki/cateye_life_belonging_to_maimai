接入 MaiBot WebUI

①零改动即时可用：本文件自包含（file:// 直接打开），从服务器插件数据目录下载 json/jsonl 拖入即可。
②挂进 WebUI：将本文件与导出的数据放到宿主 WebUI 静态目录（服务器 MaiBot\src\webui\ 下的静态挂载点，部署时用 ssh 确认具体目录）， 或由任意静态服务托管后 iframe 到 WebUI；插件侧无 HTTP 能力，不动宿主路由。
③数据刷新：面板只读文件，重新拉取数据文件后再次拖入即可；后续可加「schedule.db → episodes.json 导出脚本」获得完整 episode 历史。
