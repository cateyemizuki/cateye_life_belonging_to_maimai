# 情绪维护

这是生活插件按本项目情绪设计持续实现和重构的模块；没有把整套情绪引擎声明成 mai-love、MaiTrace 或自主规划插件的原版代码。跨模块来源仅按[第三方说明](../THIRD_PARTY.md)中已核实的文件与实现范围列出。

情绪状态使用 VAD 三轴，基线、呈现描述与事件反馈经各自映射表装载。输入/回复评估、睡眠处理、关系和活动反馈共享服务真源；没有证据时不制造真实经历或强行生成观察结论。

睡眠期事件按原有语义冻结排队，醒沿与睡眠回执共同处理，不把排队事件重复加到 VAD。稳定约定的情绪变动、冻结队列与幂等回执同文件持久化；失败恢复内存，重放不重复加减。

共享活动属性、通用 LLM 结果类型和观看任务类型位于 `core/` 叶模块；情绪服务不通过导入规划服务/观看运行器装配自己。公开配置见[配置参考](../CONFIGURATION.md)，情绪映射的用户修改位见[映射说明](../mappings/default_mappings/README.md)。
