# 属于麦麦的生活

MaiBot 的生活与陪伴插件。让麦麦按人设安排日常，根据精力、困倦和情绪调整活动，在合适的时候问候、聊天、看视频或发空间；通过 WebUI 查看这些日常记录。

当前版本 **3.18.7**。

- **日程与作息**：日常安排、实际活动、动态睡眠、午休和约定。
- **陪伴与情绪**：目标陪伴、早午晚安、想念、好感度与心情变化。
- **视频与空间**：B 站视频点播、自主选片、画面理解、观后感、聊天分享和 QQ 空间互动。
- **生活面板**：此刻状态、日程、活动历史、心情曲线、视频与动态卡片、模型用量。

## 安装

需要 MaiBot **1.0.0–1.99.99**、MaiBot SDK **2.8.0–2.99.99**，以及 `httpx>=0.24.0`、`Pillow>=9.0.0`。

在 MaiBot 根目录下载插件：

```sh
git clone https://github.com/cateyemizuki/cateye_life_belonging_to_maimai.git plugins/cateye_life_belonging_to_maimai
```

在 MaiBot 使用的 Python 环境中安装上述依赖。使用 uv 部署时，可以运行：

```sh
uv pip install "httpx>=0.24.0" "Pillow>=9.0.0"
```

随后通过宿主加载插件，在 WebUI 的「插件扩展」中打开「属于麦麦的生活」。更新时保留 `config.toml`、宿主数据目录和自定义映射，更新源码后重新加载插件。

模型任务默认使用文本任务 `replyer`、`utils`，视频和屏幕画面理解使用视觉任务 `vlm`，可在插件配置中调整。视频抽帧还需要可用的 FFmpeg；缺少解码器或视觉任务时，结果会标明降级来源。

## 首次配置

先在 WebUI 的插件配置页完成三项设置：

1. **陪伴对象与关系**：在「陪伴模块」填写目标 QQ，选择关系类型。关系类型默认为「恋人」，也可选择挚友、维护者、家人或自定义称谓。目标 QQ 留空时，仅继承宿主命令设置中唯一且可识别的 QQ 管理员；无法唯一确定时不主动私聊。
2. **作息与时区**：在「日程系统」设置起床、入睡时间，在「日程高级」设置时区。默认分别为 `07:00`、`23:00`、`Asia/Shanghai`。
3. **主动行为范围**：确认日程问候名单、视频分享对象及下表开关。日程、陪伴和视频自主观看默认开启。

| 配置项 | 默认值 | 作用 |
| --- | --- | --- |
| 视频观看 `video_watch.enabled` | 开启 | 视频工具与自主观看共用的总开关 |
| 视频自主观看 `video_autonomous.enabled` | 开启 | 允许麦麦按日程或闲暇机会自主选片；关闭后仍可工具点播 |
| 视频分享 `video_share.mode` | 自动分享 | 根据内容和聊天情况决定是否分享；可改为「影子模式」只记录判断，或「关闭」 |
| 视频分享 `video_share.allow_all_groups` | 开启 | 已注册且可路由的 QQ 群可进入分享候选，仍受活跃门槛、间隔和额度约束 |
| QQ 空间 `qzone.enabled` | 关闭 | 启用空间发布与互动，需要可用的适配器和 QQ 空间登录态 |
| 视频空间分享 `qzone_video.mode` | 影子模式 | 与聊天视频分享独立，影子模式只记录判断 |
| 屏幕感知 `screen.enabled` / `screen.tool_enabled` | 均关闭 | 分别控制主动聊天前自动看屏幕、对话中调用窥屏工具 |

屏幕功能需要统一连接插件和在线的本地客户端。截图交给已配置的视觉任务处理，默认主屏、不模糊。窥屏工具只在已核实的陪伴目标私聊中可用。首次绑定或更换目标时，插件会请求宿主重新加载自身以更新工具范围。宿主未允许自动重载时，可在插件管理页手动重新加载。QQ 空间的「旧版兼容」连接配置适用于 SnowLuma 2.0.0 以前的环境。

插件加载后会自动初始化。可用 `/lbm ops init status` 查看进度，失败项也可通过 `/lbm ops init all` 补齐。插件管理员列表留空时继承陪伴对象；无法确定管理员时，通过本机控制台操作。

关系分数、互动时间与日结印象按陪伴目标 QQ 保存。相同 QQ 更换私聊流时继续使用原关系档案。

## 常用命令

| 命令 | 用途 |
| --- | --- |
| `/lbm help` | 查看帮助和各组用法 |
| `/lbm plan list` | 查看日程 |
| `/lbm status dashboard` | 查看生活状态总览 |
| `/lbm ops init status` | 查看初始化状态 |
| `/lbm ops init all` | 检查并补齐初始化 |
| `/lbm diag rolling` | 查看实际活动与睡眠情况 |
| `/lbm diag streams` | 查看问候候选、条件与下一次触发状态 |
| `/lbm diag llm` | 查看模型调用与生成情况 |

除帮助外，上表命令需要插件管理员身份，并受相应会话范围限制。也可以使用中文命令，例如 `/麦麦生活 帮助`、`/麦麦生活 运维 初始化 状态`；完整用法以帮助为准。

## 日程、睡眠与陪伴

每天生成的是日意图，实际活动会根据当前状态、空闲时间和约定逐步安排。起床、入睡配置是作息参考，实际睡眠可能调整；午休按困倦和可用空档触发，并非每天固定发生。明确时间的约定会保留原定时刻。

日程可以带「观看视频」或「浏览 QQ」属性，分别联动视频观看和社交机会，仍受对应开关、忙闲状态、权限及额度控制。日程属性不会把一次安排自动记成已观看或已发言。

早午晚安与想念有各自的触发条件；目标私聊、其他私聊和群聊的规则不同。早午晚安不占每日可选主动预算；想念、浏览 QQ 和面向目标的自动视频分享共用该预算。想查看一次问候为何未触发，可用 `/lbm diag streams`。

情绪在清醒空闲时也会随时间逐渐回到人设基线，睡眠期间暂停日常回落，醒后按睡眠情况统一恢复。普通闲聊通常只带来很小的变化，明确的实际影响和重大事件会有更大的响应；亲切语气或活泼人设本身不作为持续加分的依据。

## 视频观看与分享

可以在对话中让麦麦使用 `lbm_watch_bili_video` 点播 B 站链接或 BV 号，并查询进度、结果或取消任务。这是提供给 bot 调用的工具。工具点播受观看总开关和媒体处理限制，不占自主观看额度，也不受自主选片的播放量门槛限制。

自主观看在实际活动和闲暇机会中进行，默认额度如下：

| 场景 | 默认安排 |
| --- | --- |
| 带「观看视频」属性的日程 | 看完一支再选下一支，单段最多 10 支；每天最多 4 场 |
| 普通闲暇日程顺便看 | 每份原计划只判断一次，10% 概率，最多一支；每天最多 3 场 |
| 没有当前活动时的空隙观看 | 每天最多 2 场，至少间隔 60 分钟 |
| 全部自主观看合计 | 每天最多 8 场、240 分钟 |

上述数值可在「视频自主观看」中调整。暂停、恢复活动不会重新获得一次概率或十支预算；实际观看还受睡眠、硬约定、忙碌、聊天和剩余活动时间限制。自主选片默认要求播放量至少 50000，设为 `0` 可关闭该项门槛。

视频通过画面采样理解，默认直接读取媒体流，不先下载全片。当前多 P 视频仅支持第 1 P，无音轨转写；只有标题、简介等元信息时会标明来源。只有元信息的降级结果不会当作完整观看结果自动分享。

聊天视频分享与视频空间分享分别配置。聊天分享默认允许陪伴目标私聊和符合条件的群聊进入候选，由独立判断决定是否发送；观看完成不代表一定分享。自动聊天分享默认所有目标合计每天最多 3 次、同一聊天最多 1 次，两次分享至少间隔 6 小时。

## 生活面板与图片

面板区分计划和实际活动，可按日期查看日程与历史。心情曲线有独立的 6 小时、24 小时、3 天、7 天范围和缩放控件，悬停或轻点显示点值。睡觉、午休和用餐会使用更直观的显示名称，原日程描述保留。

娱乐页在视频与动态之间切换，两类内容均用卡片网格展示，每页按当前列数最多加载约三行。视频卡包含原始标题、封面、观后感、播放量、点赞、投币和收藏；动态卡显示图片与文案。长内容省略预览，点击卡片查看完整详情。

缺失的旧视频元信息会在后台补齐，标为「历史补录 · 当前数据」；观看时记录与当前补录分开展示。空间图片仅从已确认发送的动态后台读取。补录不会重新观看、重发动态或改写原观看时间。

封面和动态图片需要宿主自定义页面允许相应的 B 站、QQ 图片 CDN。升级后如果全部显示「图片暂时无法加载」，先按 `Ctrl+F5` 强制刷新；仍失败时检查宿主图片策略和浏览器网络限制。
