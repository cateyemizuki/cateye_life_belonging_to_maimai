# 跨模块行为编排

本层是生活插件的集成与持续重构代码，不冒认某个上游插件的完整原版。第三方文件/协议参考按[来源说明](../THIRD_PARTY.md)逐项列出。

- 视频自主选片、额度预留/结算与观看任务协调调用 `video_watch` 公共能力；工具点播和自主入口分开。
- 日程模块属性先经 `core/activity_attributes.py` 规范化与守护，再由实际 episode 触发；属性 `null` 不代表专门模块许可。
- 普通日程顺便观看需要明确可中断、当前可响应、一次性概率和配额；不改变原 `goal_type` 或可中断性来凑条件。
- `video_watch_budget.py` 是本项目自研的视频机会/受理任务账：原日表计划身份累计一次概率和最多支数，暂停恢复不重置；缺计划身份才回退实际 episode 并沿恢复链继承。它不复制日程状态，日配额/owner 仍归实际 episode，未知受理保留冻结预占而不冒充已观看。
- `SmallEventActions` 的 QQ 可选机会保留目标、权限、预算、冷却及 episode 防重；属性不能直接发送消息。
- 观看、聊天分享、空间视频发帖各有独立持久回执；未知结果不伪装成功或无条件重试。

共享协议留在 `core/` 叶模块，运行器从组合根注入；不借包导入隐式装配其他服务。
